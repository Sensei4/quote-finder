# Quote Finder

Сайт для поиска цитат в загруженных документах.

## Технологии

- Node.js + Express (бэкенд)
- React (фронтенд)
- PostgreSQL (база данных)
- Docker (контейнеризация)

## Функциональность

- Загрузка документов (TXT, PDF, DOCX)
- Полнотекстовый поиск с учётом морфологии
- Просмотр контекста цитат
- Экспорт результатов в разные форматы
