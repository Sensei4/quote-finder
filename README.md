# Quote Finder

Сайт для поиска цитат в загруженных документах.

## ✅ Реализовано

### Бэкенд (Node.js + Express)

- Загрузка документов (TXT, PDF, DOCX, RTF, DOC)
- Извлечение текста из документов
- Разбивка на предложения
- Полнотекстовый поиск с учётом русской морфологии
- Подсветка найденных слов
- Получение контекста цитат

### База данных (PostgreSQL)

- Таблицы documents и sentences
- Триггер для автоматического tsvector
- Индекс GIN для быстрого поиска

### Инфраструктура

- Docker контейнер для PostgreSQL
- Git-репозиторий с историей коммитов

## 🚧 В разработке

- Фронтенд на React
- Экспорт результатов
- Деплой на сервер

## 🛠 Технологии

- Node.js + Express
- PostgreSQL
- Docker
- React (скоро)
